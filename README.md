🚗 Vehicle Rental System

A full-stack Vehicle Rental and Sales Management System built with the MERN stack (MongoDB, Express, React, Node.js). It supports three roles: Users, Distributors, and Admins, each with distinct capabilities.

---

🔧 Tech Stack
- Frontend: React.js

- Backend: Node.js + Express.js

- Database: MongoDB + Mongoose

- Authentication: JWT

- UI/UX: CSS Modules /Bootstrap 

- State Management: React Context / Redux

  ---

🧑‍💻 Roles & Features

🔹 User
- Sign up / log in

- Browse sales and rental vehicles

- Request to become a distributor

🔸 Distributor
- Add rental and sales vehicles

- View own revenue reports

- Respond to tasks from admin

- Manage reviews and messages for their vehicles

🔺 Admin
- CRUD on all vehicles, users, and distributors

- Approve distributor requests

- Assign tasks and send messages to distributors

- View overall platform revenue reports
